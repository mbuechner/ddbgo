By default, helm uninstall removes all chart-created resources except the three
PersistentVolumeClaims and chart-created Secrets. A reinstall with the same
release name and namespace adopts retained PVCs and Secrets that still carry
this release's Helm ownership metadata. Existing Secret data is reused so that
persistent MariaDB and Redis data keep matching their credentials.
